Phishing URL Detection Using Python

Project Overview
This project is a simple Python-based tool that identifies potentially suspicious URLs by checking different URL characteristics.

Features
- Checks URL length.
- Detects common private IP address patterns.
- Identifies suspicious keywords such as login, verify, password, and banking.
- Checks suspicious special characters such as @ and !.
- Displays a final result indicating whether the URL is potentially safe or suspicious.

Technologies Used
- Python
- String Operations
- Conditional Statements
- Loops

How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run `phishing_detector.py`.
5. Enter a URL when prompted.
6. View the detection result.

## Note
This is a beginner-level rule-based detection project. A potentially safe result does not guarantee that a URL is completely safe.
